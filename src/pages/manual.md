# MechSim 用户使用手册

> 版本 v0.0.1 · 机电仿真平台

---

## 1. 平台概述

MechSim 是一款面向机电系统建模与仿真的 Web 平台。用户可通过 Web 界面完成仿真用例管理、模型参数编辑、Simulink 仿真任务调度以及仿真结果的可视化分析，无需直接操作 MATLAB 环境。

**核心能力：**

- **多版本 / 多系统** — 支持 3X、5X 等多代产品线的并行仿真
- **参数化管理** — 用例参数以树形结构组织，支持逐级编辑与差异对比
- **异步仿真** — MATLAB 引擎池管理，后台执行 Simulink 仿真，不阻塞操作
- **可视化分析** — 时域 / 频域双图展示，支持拖拽缩放与 SVG 导出

**技术架构：**

```
React 前端 (Ant Design + uPlot) → REST API → FastAPI → MATLAB Engine Pool → Simulink 模型
```

## 3. 用户切换

页面右上角提供用户名输入框，输入有效用户名后点击「确定」即可切换当前操作身份。所有 API 请求会自动附加 `X-User` 请求头，后端依此进行权限校验。

> **注意：** 切换用户后页面会自动刷新，请先保存正在编辑的内容。可用的用户名列表由系统配置文件控制。

## 4. 创建用例

用例是仿真任务的源头，定义了模型系统、版本、参数和扰动配置。

**操作步骤：**

1. 点击左侧「用例编排」进入用例列表页
2. 点击左侧面板顶部的「+ 添加用例」按钮
3. 在弹出对话框中输入用例名称（必填）和描述（可选）
4. 点击「添加」，系统自动创建用例并进入编辑视图

> **自动填充：** 用例创建时，系统会从 `model_info.json` 中自动匹配 `model_name` 和 `init_script`。`model_verison` 默认为 "3X"，`model_productivity` 默认为 "100WPH"。

## 5. 编辑用例参数

选中用例后，右侧主区域显示用例详情与参数编辑区，通过标签页切换不同功能面板。

### 5.1 参数编辑 (ParamTab)

1. **选择模型系统** — 通过「选择模型」面板，依次选择**产品版本**（如 3X / 5X）和**子系统**（如 WS、RS、BM 等），系统自动加载对应的参数表。
2. **编辑参数值** — 参数以树形结构展示（命名空间 → 变量 → 值），点击具体变量值即可内联编辑。修改后单元格会高亮为浅蓝色。
3. **保存** — 点击右上角「保存」按钮。保存前系统会通过 `POST /diff_case` 对比当前参数与系统默认值的差异。

> **提示：** 变量名右侧如果有 `_labels` 和 `_units` 元数据，会在悬浮时显示中文标签和物理单位。

### 5.2 扰动配置 (DisturbTab)

- 左侧树形展示 `Disturbance/data_raw/` 下的文件目录
- 选择 CSV / Excel 文件可预览扰动数据列
- 选中后生成扰动 JSON 配置，保存到用例的 `disturbance` 字段

## 6. 复制 / 共享 / 删除

在用例详情面板的顶部工具栏可执行以下操作：

| 操作 | 按钮 | 说明 |
|------|------|------|
| 复制 | 复制 | 创建当前用例的副本，名称自动加上 "_copy" 后缀 |
| 共享 | 共享 | 将用例分享给其他用户，使其也可以查看和编辑 |
| 删除 | 删除 | 软删除用例（标记 `is_deleted=true`），数据可恢复 |

> **权限：** 仅用例创建者可以编辑、复制、共享和删除。被共享的用户只能查看。

## 7. 创建与运行任务

**操作步骤：**

1. 在用例编辑页面配置好参数后，点击「创建任务」按钮
2. 弹出「参数变更预览」对话框，展示当前参数与系统默认参数的差异：
   - **绿色** — 新增或修改的值
   - **红色** — 被移除的值
3. 确认无误后点击「运行」，系统依次执行：
   - `POST /add_tasks` — 从用例创建 SimTask 记录
   - `POST /run_tasks` — 提交任务到 MATLAB 引擎池

> **内部流程：** 任务提交后，MATLAB 引擎执行 `run_tasks.m` 脚本：加载模型 → 应用参数差异 → 运行 Simulink 仿真 → `SimOut2Csv.m` 输出 CSV 信号文件到 `WorkSpace/task_{id}/`。

## 8. 任务管理

进入「任务管理」页面，以表格形式展示所有仿真任务。运行中的任务每 3 秒自动刷新状态。

### 8.1 任务状态

| 状态 | 标签 | 说明 |
|------|------|------|
| `pending` | 等待中 | 任务已创建，等待引擎池中分配线程 |
| `running` | 运行中 | MATLAB 正在执行 Simulink 仿真 |
| `done` | 已完成 | 仿真成功，CSV 结果文件已写入 workspace |
| `failed` | 失败 | 仿真出错，查看 error 字段了解原因 |
| `cancelled` | 已取消 | 用户手动取消，对应 MATLAB 进程被强制终止 |

### 8.2 任务操作

- **查看详情** — 对于已完成任务，点击「详情」跳转到数据可视化页面
- **取消** — 对于 pending 或 running 状态的任务，点击「取消」终止执行
- **删除** — 软删除任务记录
- **查看参数变更** — 点击「查看」链接，弹出任务的参数差异详情

## 9. 数据可视化

数据可视化页通过两种方式访问：
1. 从任务列表点击「详情」
2. 通过「工作路径数据」输入 workspace 路径

### 9.1 信号选择

左侧「信号列表」面板列出所有可用的仿真输出信号（从 `signals_index.json` 解析）。勾选信号后自动加载其时域和频域数据。支持关键字搜索和「全不选」批量清除。

### 9.2 时域图与频域图

- **时域图** — 横轴为时间（秒），纵轴为信号数值。鼠标悬停显示光标定位标签
- **频域图（FFT）** — 横轴为频率（Hz，对数轴 1–20000 Hz），纵轴为频谱幅值
- 各信号由不同颜色区分，图例显示信号名称
- 当数据点数超过 20,000 时自动降采样，保证图表响应性能

### 9.3 缩放与还原

- **拖拽缩放** — 在图表上水平拖拽选中区域，松开后加载该区间的高精度数据
- **双击还原** — 双击图表还原为全量数据视图

### 9.4 导出图表

每个图表右上角有「导出 SVG」按钮，点击后输入文件名即可将当前图表（含图例）导出为 SVG 矢量图。

## 10. 工作路径数据

「工作路径数据」允许直接通过 workspace 路径加载仿真结果，不依赖数据库中已注册的任务。适用于：

- 查看非本平台产生的仿真结果（手动运行 MATLAB 生成的数据）
- 从其他机器 / 共享目录直接加载数据

**使用方式：**

1. 进入「结果分析 → 工作路径数据」
2. 输入 workspace 绝对路径或相对于 `WORKSPACE_ROOT` 的名称（如 `task_12`）
3. 点击「查看」加载信号索引，后续操作与数据可视化页一致

## 11. API 接口参考

后端提供 RESTful API，基础路径为 `/api/v1`。所有请求应携带 `X-User` 请求头。

### 11.1 用例相关

| Method | Path | 说明 |
|--------|------|------|
| POST | `/sim/add_case` | 创建用例 |
| GET | `/sim/queue_cases` | 获取当前用户的用例列表 |
| GET | `/sim/get_case/{id}` | 获取单个用例详情 |
| PUT | `/sim/update_case/{id}` | 更新用例 |
| DELETE | `/sim/delete_case/{id}` | 删除用例 |
| POST | `/sim/share_case/{id}` | 共享用例 |
| POST | `/sim/unshare_case/{id}` | 取消共享 |
| GET | `/sim/case_shares/{id}` | 查看用例共享列表 |
| GET | `/sim/queue_case/{flow_instance_id}` | 按流程实例 ID 查用例 |
| POST | `/sim/diff_case/{id}` | 对比用例参数与默认值 |

### 11.2 任务相关

| Method | Path | 说明 |
|--------|------|------|
| POST | `/sim/add_tasks` | 从用例创建任务 |
| POST | `/sim/run_tasks` | 提交任务到 MATLAB 引擎池 |
| GET | `/sim/queue_tasks` | 获取所有任务列表 |
| GET | `/sim/get_task_status/{task_id}` | 查询任务状态 |
| POST | `/sim/cancel_task/{task_id}` | 取消运行中的任务 |
| DELETE | `/sim/delete_task/{id}` | 删除任务 |

### 11.3 数据相关

| Method | Path | 说明 |
|--------|------|------|
| GET | `/sim/task_data/{task_id}` | 获取任务信号索引 |
| POST | `/sim/task_data/{task_id}/signals` | 加载指定信号数据 |
| GET | `/sim/workspace_data` | 通过 workspace 获取信号索引 |
| POST | `/sim/workspace_data/signals` | 通过 workspace 加载信号 |

### 11.4 模型信息

| Method | Path | 说明 |
|--------|------|------|
| GET | `/sim/update_model_info` | 扫描 Sys/ 重建 model_info.json |
| POST | `/sim/queue_model_info` | 获取当前模型信息 |
| GET | `/sim/model_image/{sys_name}` | 获取系统架构图片 |

### 11.5 扰动数据

| Method | Path | 说明 |
|--------|------|------|
| GET | `/sim/queue_disturbances` | 获取扰动文件目录树 |
| POST | `/sim/get_disturbance_info` | 读取扰动文件内容 |

### 11.6 通用响应格式

```json
{ "success": true, "message": "...", "data": {...} }
```
