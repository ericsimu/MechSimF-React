# MechSim 用户使用手册

> 版本 v0.0.1 · 机电仿真平台

---

## 1. 平台概述

MechSim 是云端机电一体化仿真 Web 平台，打通机电模型从工程管理、参数配置、任务计算到数据复盘全流程。平台支持 3X/5X 多产品线多版本并行仿真；树形层级化参数库实现分级编辑、版本留存与差异对比；异步后台算力调度保障仿真与前端操作互不干扰，任务进度实时同步；配套时域 + 频域联合可视化分析工具，支持交互缩放、图表导出，高效完成机电系统多工况仿真验证与性能评估。

**核心功能：**

- **多产品线并行协同仿真** — 平台兼容 3X、5X 等全系列设备产品线模型，支持多版本工程、多套机电系统同步并发仿真计算，可批量提交差异化工况任务，实现跨型号、多方案同步对比推演，大幅缩短多方案迭代验证周期。
- **层级化可视化参数管控体系** — 采用分层树形结构统一组织整机、子系统、零部件各级仿真参数，支持逐层精细化编辑、参数模板存档复用、多版本参数集差异一键比对，清晰定位参数改动对系统性能的影响，实现参数变更可追溯、可复用、可对比。
- **异步后台分布式仿真调度** — 仿真任务提交后自动转入后台算力集群独立运算，全程不占用前端界面操作权限，用户可同步新建模型、配置参数或查看历史报告；平台实时推送任务排队、计算中、异常、完成等全状态信息，进度动态刷新，任务运行状态一目了然。
- **时频联合一体化结果分析** — 仿真输出数据配套时域、频域双视图联动展示，支持曲线框选缩放、局部放大、坐标轴自定义、多曲线叠加对比等交互式操作；原始仿真数据、可视化图表均支持离线导出存档，满足报告编制、离线复盘、二次深度分析需求。

## 2. 导航栏介绍

左侧导航栏为平台的主要功能入口，各功能说明如下：

| 导航项 | 功能说明 |

## 3. 用户操作总体流程

使用 MechSim 完成一次仿真的典型流程如下：

```
账号登录 → 新建仿真工程用例 → 选定目标机电模型体系 → 层级化参数整定配置 →（可选）工况扰动配置 → 工程用例持久化存储 → 调度仿真计算任务 → 时频联合结果分析
```

1. **登录系统** — 输入授权账号凭证完成身份校验，登入仿真业务操作主界面。
2. **创建用例** — 创建独立仿真工程载体，自定义工程标识名称、业务描述信息，用于区分不同工况、不同方案仿真任务。
3. **配置模型** — 按需选定对应产品线版本、整机系统及下属各级子系统，进入参数编辑界面完成整机、零部件参数数值整定。
4. **配置扰动**（可选）— 关联外部扰动数据源文件，将激励扰动工况绑定至当前仿真用例，复现实际运行波动、冲击等特殊工况场景。
5. **保存用例** — 持久存储当前整套模型参数、扰动工况等全部配置信息，生成可复用、可追溯的标准化仿真工程。
6. **创建并运行任务** — 预览本次参数修改差异校验无误后，提交仿真计算请求至后台算力集群，启动异步仿真运算任务。
7. **查看结果** — 跳转至数据可视化模块，加载对应任务工作空间数据，完成时域响应曲线、频域特性曲线联合观测与分析。

## 4. 详细操作步骤

### 4.1 登录系统

启动系统后自动跳转至登录认证界面，登录操作流程如下：

1. 在用户名输入框中录入已授权的登录账号；
2. 点击界面「登录」按钮，或按下键盘 Enter 键提交身份校验；
3. 如果用户名有效，进入平台主页；否则提示"无权限"。

> **可用的用户名：** `user1`、`user2`、`admin`

登录后，右上角显示当前用户名。如需切换用户：
1. 点击右上角用户名，修改为新用户名
2. 点击「确定」；如需退出当前用户，点击「退出登录」返回登录页

> 切换用户或退出登录前，请确保已保存正在编辑的内容。

---

### 4.2 用例管理

进入「用例编排」页面，左侧为用例列表，右侧为用例详情与编辑区。

#### 4.2.1 创建用例

1. 在左侧用例列表顶部，点击「新建」按钮
2. 在弹出的"创建用例"对话框中填写：
   - **用例名称**（必填）— 为该用例命名
   - **用例描述**（选填）— 对该用例的补充说明
3. 点击「添加」完成创建

创建成功后，用例会自动出现在左侧列表中并被选中。

#### 4.2.2 编辑用例基本信息

选中用例后，右侧顶部显示用例信息表格（名称、描述、创建者、创建时间）：

- 点击**名称**或**描述**单元格可内联编辑，修改后按 Enter 或点击其他位置保存
- 按 Esc 取消编辑

#### 4.2.3 复制用例

1. 选中要复制的用例
2. 在用例信息表格的操作列，点击「复制」按钮
3. 系统自动创建副本，名称在原名称后追加 `_copy` 后缀

#### 4.2.4 共享用例

将用例分享给其他用户，使其也能查看和编辑：

1. 选中要共享的用例
2. 点击「共享」按钮，弹出"共享用例"对话框
3. 对话框上方列出已共享的用户（如有），每位用户旁有「移除」按钮
4. 在下方的输入框中输入要添加的用户名，点击「添加」

> 仅用例创建者可以共享和取消共享。

#### 4.2.5 删除用例

1. 选中要删除的用例
2. 点击「删除」按钮
3. 在确认对话框中点击「确认」完成删除（点击「取消」则放弃）

---

### 4.3 模型选择与参数配置

选中用例后，下方标签页区域包含四个功能页签。前两个为核心操作：

#### 4.3.1 模型选择（页签一）

在运行仿真前，需先选择仿真的目标系统：

| 配置项 | 选项 | 说明 |
|--------|------|------|
| **版本** | 3X / 5X | 选择产品代际 |
| **产率** | 100WPH / 150WPH / 200WPH / 295WPH / 340WPH| 选择产线速率 |
| **系统选择** | WS / RS / BM 等 | 选择具体子系统（根据模型信息动态加载） |
| **仿真时间 (s)** | 数值输入 | 设定仿真时长，留空使用默认值；不可超过 19.2 秒 |

选择系统后，右侧显示当前系统的架构图片。切换系统时会自动加载对应的参数表。

#### 4.3.2 参数配置（页签二）

参数配置页签为左右分栏布局：

**左侧 — 参数树：**
- 参数以树形结构组织（命名空间 → 变量分类 → 具体变量）
- 点击 `▶` 展开子节点，点击 `▼` 收起
- 点击叶子节点（具体变量），右侧显示对应的编辑表单

**右侧 — 参数编辑：**
- 表格显示选中节点的所有参数：参数名、参数值、单位
- 在"参数值"列直接修改数值
- 修改后点击其他位置（失焦）自动保存该字段
- 鼠标悬停在参数名上可显示中文标签和物理单位

参数修改后，记得点击页面上方工具栏的「保存」按钮将更改保存到用例。

> 左右分栏的宽度可通过中间的拖动条自由调整。

---

### 4.4 扰动配置（页签三）

扰动配置允许为仿真附加外部扰动数据文件：

**左侧 — 扰动文件目录树：**
- 以树形结构展示可用的扰动数据文件
- 点击 `▶` / `▼` 展开或收起目录

**操作步骤：**

1. 在左侧目录树中浏览文件
2. 勾选要使用的扰动文件的复选框
3. 点击文件名预览该文件的数据波形
4. 右侧预览区以图表方式显示各列数据，顶部有可切换的列名标签

勾选的扰动文件会自动保存到用例的扰动配置中。

---

### 4.5 创建与运行仿真任务

配置好参数后，即可创建仿真任务：

1. 在用例编辑页面，点击上方工具栏的「创建任务」按钮
2. 弹出"创建仿真任务"对话框，显示**参数变更预览**：
   - 绿色行 — 新增或修改的参数值
   - 红色行 — 被移除的参数值
   - 显示为空 — 表示参数无变更
3. 确认变更无误后，点击「运行」提交任务

任务提交后，系统在后台执行仿真，用户可在"任务管理"页面查看进度。

---

### 4.6 任务管理

进入「任务管理」页面，以表格形式展示所有仿真任务。

#### 4.6.1 任务列表

表格包含以下列：

| 列名 | 说明 |
|------|------|
| ID | 任务编号 |
| 名称 | 任务名称 |
| 系统 | 仿真的子系统名称 |
| 模型 | 使用的模型名称 |
| 版本 | 产品版本 |
| 产率 | 产线速率 |
| 状态 | 任务当前状态（见下表） |
| 参数变更 | 点击"查看"链接查看参数差异详情 |
| 创建时间 | 任务创建时间 |
| 操作 | 可执行的操作按钮 |

#### 4.6.2 任务状态

| 状态标签 | 含义 |
|----------|------|
| 等待中 | 任务已创建，排队等待执行 |
| 运行中 | 仿真正在执行中 |
| 已完成 | 仿真成功完成，结果数据已生成 |
| 失败 | 仿真过程中出现错误 |
| 已取消 | 用户手动取消了该任务 |

> 当存在"等待中"或"运行中"的任务时，任务列表每 3 秒自动刷新。

#### 4.6.3 任务操作

- **查看结果** — 对于"已完成"的任务，点击「结果」按钮跳转到数据可视化页面
- **取消任务** — 对于"等待中"或"运行中"的任务，点击「取消」按钮终止执行
- **删除任务** — 点击「删除」按钮，确认后删除该任务记录
- **查看参数变更** — 点击"参数变更"列的「查看」链接，弹出参数差异详情

---

### 4.7 数据可视化

数据可视化页面用于查看仿真结果的时域图和频域图。

#### 4.7.1 进入方式

- **从任务进入：** 在「任务管理」页面，点击已完成任务的「结果」按钮
- **从 workspace 进入：** 输入 workspace 路径直接加载（适用于查看未注册在数据库中的仿真数据）

#### 4.7.2 信号选择

页面左侧为"信号列表"面板：

- 列出当前任务所有可用的输出信号
- 勾选信号复选框，自动加载其时域和频域数据
- 支持**搜索**：在搜索框中输入关键字筛选信号
- 点击「全不选」批量取消所有已选信号

#### 4.7.3 图表操作

**时域图**
- 横轴：时间（秒）
- 纵轴：信号数值
- 不同信号以不同颜色区分，图例显示信号名称

**频域图（FFT）**
- 横轴：频率（Hz），对数坐标（1 – 20,000 Hz）
- 纵轴：频谱幅值

**缩放与还原**
- **拖拽缩放** — 在图表上水平拖拽选中一段区域，松开后加载该区间的高精度数据
- **双击还原** — 双击图表恢复原始全量视图

**导出图表**
- 点击图表右上角的「导出 SVG」按钮
- 在弹出的输入框中输入文件名
- 点击「确认」保存为 SVG 矢量图

---

### 4.8 从 workspace 路径加载数据

此功能允许直接通过文件路径加载仿真结果，无需关联数据库中的任务：

1. 在地址栏访问 `/data-ws?workspace=路径名`（路径名相对于工作空间根目录）
2. 系统加载该路径下的信号列表
3. 后续操作（选择信号、查看图表、缩放导出）与标准数据可视化页面一致

> 适用场景：查看手动运行 MATLAB 生成的仿真数据，或从其他机器共享目录加载数据。
