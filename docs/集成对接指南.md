# MechSimF-React 集成对接指南

本文档说明如何将 MechSimF-React 页面嵌入到更高层级的父项目中，以及如何对接父项目的登录认证系统。

---

## 一、页面嵌入方式

### 方式 1：iframe 嵌入（最简单）

父项目通过 `<iframe>` 加载 MechSimF-React 的独立部署页面。

```html
<!-- 父项目代码 -->
<iframe src="http://mechsim-react:5173/cases" width="100%" height="100%" />
```

**优点**：完全隔离，无冲突
**缺点**：URL 不同步，SEO 差，消息通信需要 postMessage

#### 跨域通信

```javascript
// 父项目 → MechSimF
iframe.contentWindow.postMessage({
  type: 'SET_USER',
  username: 'zhangsan'
}, 'http://mechsim-react:5173')

// MechSimF 接收
window.addEventListener('message', (e) => {
  if (e.data.type === 'SET_USER') {
    localStorage.setItem('current_user', e.data.username)
  }
})
```

### 方式 2：路由嵌入（推荐）

父项目使用 React Router，将 MechSimF 的页面路由作为子路由挂载。

**步骤 1：导出页面组件和路由配置**

创建 `src/entry.tsx`，将页面组件和路由配置统一导出：

```tsx
// src/entry.tsx
export { default as CaseList } from './pages/CaseList'
export { default as Tasks }   from './pages/Tasks'
export { default as DataViewer } from './pages/DataViewer'
export { default as Placeholder } from './pages/Placeholder'

// 路由配置，供父项目直接使用
import type { RouteObject } from 'react-router-dom'
import CaseList from './pages/CaseList'
import Tasks from './pages/Tasks'
import DataViewer from './pages/DataViewer'
import Placeholder from './pages/Placeholder'

export const mechsimRoutes: RouteObject[] = [
  { path: '/cases',        element: <CaseList /> },
  { path: '/cases/:taskId', element: <CaseList /> },  // 可选参数
  { path: '/tasks',        element: <Tasks /> },
  { path: '/data/:taskId?', element: <DataViewer /> },
  { path: '/data-manage',  element: <Placeholder /> },
  { path: '/tools',        element: <Placeholder /> },
  { path: '/manual',       element: <Placeholder /> },
  { path: '/indicators',   element: <Placeholder /> },
  { path: '/reports',      element: <Placeholder /> },
  { path: '/logs',         element: <Placeholder /> },
]
```

**步骤 2：父项目挂载路由**

```tsx
// 父项目的路由配置
import { mechsimRoutes } from 'mechsimf-react/entry'

const router = createBrowserRouter([
  { path: '/',         element: <Home /> },
  { path: '/dashboard', element: <Dashboard /> },
  // 将 MechSimF 路由挂载到 /mechsim 路径下
  {
    path: '/mechsim',
    children: mechsimRoutes,  // 直接展开
  },
])
```

**步骤 3：移除 MechSimF 自带的 BrowserRouter**

修改 `src/main.tsx`，不再创建独立 Router：

```tsx
// src/main.tsx — 独立部署入口
import { BrowserRouter } from 'react-router-dom'
import App from './App'
createRoot(document.getElementById('root')!).render(
  <BrowserRouter><App /></BrowserRouter>
)
```

父项目嵌入时，MechSimF 页面作为普通 React 组件渲染，使用父项目的 Router 上下文。

### 方式 3：微前端（Module Federation / qiankun / wujie）

通过 Module Federation 或微前端框架暴露 MechSimF 的页面模块。

#### Vite + Module Federation

```ts
// vite.config.ts
import federation from '@originjs/vite-plugin-federation'

export default defineConfig({
  plugins: [
    federation({
      name: 'mechsimf',
      filename: 'remoteEntry.js',
      exposes: {
        './CaseList': './src/pages/CaseList.tsx',
        './Tasks': './src/pages/Tasks.tsx',
        './DataViewer': './src/pages/DataViewer.tsx',
      },
      shared: ['react', 'react-dom', 'react-router-dom', 'antd'],
    }),
  ],
  build: {
    target: 'esnext',
  },
})
```

父项目直接 import：

```tsx
const CaseList = React.lazy(() => import('mechsimf/CaseList'))
```

### 方式 4：npm 包发布

将 MechSimF-React 构建产物发行为 npm 包。

```json
// package.json
{
  "name": "@mechsim/react",
  "main": "dist/entry.js",
  "module": "dist/entry.es.js",
  "files": ["dist"],
  "exports": {
    ".": "./dist/entry.js",
    "./pages/*": "./dist/pages/*.js",
    "./types": "./dist/types/api.d.ts"
  }
}
```

## 二、登录认证对接

MechSimF-React 本身**不做用户认证**，所有 API 请求通过 `X-User` 请求头传递当前用户名。父项目需要在渲染 MechSimF 页面前完成以下步骤：

### 核心机制

所有 API 请求通过 `src/api/index.ts` 中的 `request()` 函数发送：

```typescript
async function request<T>(url: string, options: RequestInit = {}) {
  const res = await fetch(`${BASE}${url}`, {
    headers: {
      'Content-Type': 'application/json',
      'X-User': getCurrentUser(),  // ← 从 localStorage 读取当前用户
      ...options.headers,
    },
    ...options,
  })
  return res.json()
}
```

`getCurrentUser()` 默认从 `localStorage.current_user` 读取，无值时返回 `'user1'`。

### 接入方案 A：localStorage 写入（最简单）

父项目完成登录认证后，将用户名写入 `localStorage`，再加载 MechSimF 页面。

```javascript
// 父项目登录成功后
localStorage.setItem('current_user', loginResponse.username)
// 然后渲染 MechSimF 页面
```

如果 MechSimF 与父项目**同域**部署（共享 localStorage）：

```javascript
// 登录成功回调
onLoginSuccess(user) {
  localStorage.setItem('current_user', user.name)
  // 无需额外操作，MechSimF 的 API 请求自动携带 X-User
}
```

如果**跨域**部署，需通过 URL 参数或 postMessage 传递：

```javascript
// 父项目通过 URL 参数传递
const username = 'zhangsan'
iframe.src = `http://mechsim-react:5173/cases?user=${encodeURIComponent(username)}`
```

MechSimF 在初始化时从 URL 读取：

```tsx
// src/main.tsx 或 src/App.tsx
useEffect(() => {
  const params = new URLSearchParams(window.location.search)
  const user = params.get('user')
  if (user) {
    localStorage.setItem('current_user', user)
    // 清除 URL 参数
    window.history.replaceState({}, '', window.location.pathname)
  }
}, [])
```

### 接入方案 B：替换 getCurrentUser 实现

父项目通过 npm 包或 Module Federation 引入页面时，可以替换用户获取逻辑。

父项目提供 `UserContext`：

```tsx
// 父项目
import { createContext, useContext } from 'react'

export const AuthContext = createContext({ username: '', token: '' })

export function useAuth() {
  return useContext(AuthContext)
}
```

MechSimF 入口适配：

```tsx
// src/entry.tsx — 嵌入模式入口（不使用 localStorage）
import { getCurrentUser, setCurrentUser } from './api/index'

// 父项目注入用户获取函数
export function injectAuth(getUser: () => string) {
  // 用高阶函数替换模块内的 getCurrentUser 调用
  // 方式：通过 window 全局变量
  ;(window as any).__mechsim_get_user = getUser
}
```

修改 `api/index.ts` 支持自定义用户获取：

```typescript
// src/api/index.ts
export function getCurrentUser(): string {
  // 优先使用父项目注入的函数
  if ((window as any).__mechsim_get_user) {
    return (window as any).__mechsim_get_user()
  }
  // 回退到 localStorage
  return localStorage.getItem('current_user') || 'user1'
}
```

父项目注入：

```tsx
// 父项目
import { injectAuth } from 'mechsimf-react'
import { useAuth } from './AuthContext'

function App() {
  const { username } = useAuth()
  useEffect(() => {
    injectAuth(() => username)
  }, [username])

  return <CaseList />
}
```

### 接入方案 C：URL 查询参数

父项目在路由跳转时携带用户名：

```
http://mechsim-react:5173/cases?user=zhangsan
```

MechSimF 根组件检测并存储：

```tsx
function App() {
  useEffect(() => {
    const params = new URLSearchParams(location.search)
    const user = params.get('user')
    if (user) {
      localStorage.setItem('current_user', user)
      // 清理 URL
      const url = new URL(location.href)
      url.searchParams.delete('user')
      window.history.replaceState({}, '', url.toString())
    }
  }, [])
  // ...
}
```

## 三、API 代理配置

### 开发环境（Vite）

```ts
// vite.config.ts
export default defineConfig({
  server: {
    proxy: {
      '/api': 'http://mechsim-backend:8000',  // 指向后端地址
    },
  },
})
```

### 生产环境（Nginx）

```nginx
location /api/ {
    proxy_pass http://mechsim-backend:8000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}
```

### 跨域配置（后端 FastAPI）

```python
# main.py
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://parent-app:3000", "http://mechsim-react:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

## 四、构建配置

### 嵌入模式构建

```ts
// vite.config.ts
export default defineConfig({
  base: '/mechsim/',  // 如果部署在子路径下
  build: {
    outDir: 'dist',
    lib: {
      entry: 'src/entry.tsx',
      formats: ['es'],
      fileName: 'mechsim-react',
    },
    rollupOptions: {
      external: ['react', 'react-dom', 'react-router-dom', 'antd'],
      output: {
        globals: {
          react: 'React',
          'react-dom': 'ReactDOM',
          'react-router-dom': 'ReactRouterDOM',
          antd: 'antd',
        },
      },
    },
  },
})
```

### 环境变量

```bash
# .env.embed
VITE_API_BASE=/api/v1/sim
VITE_AUTH_MODE=localStorage  # 'localStorage' | 'inject' | 'url'
VITE_PARENT_ORIGIN=http://parent-app:3000
```

## 五、接入步骤总结

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 选择嵌入方式 | iframe / 路由嵌入 / 微前端 / npm 包 |
| 2 | 选择认证方案 | localStorage / 注入函数 / URL 参数 |
| 3 | 配置 API 代理 | Vite proxy 或 Nginx 反向代理 |
| 4 | 父项目登录后写入用户 | `localStorage.setItem('current_user', name)` |
| 5 | 渲染 MechSimF 页面 | 按选择的嵌入方式挂载 |
| 6 | 验证 | 打开 Network 面板，确认 X-User 头正确传递 |

**最小接入示例**（同域 iframe）：

```html
<script>
  // 父项目登录成功后
  localStorage.setItem('current_user', 'zhangsan')
</script>
<iframe src="/mechsim-react/cases" width="100%" height="100vh" />
```
